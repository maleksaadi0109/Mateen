# تشغيل مراجعة مَتِين

## الصلاحيات والحسابات

- لا يُعيَّن أي مسؤول تلقائيًا، ولا يوجد مسار API يسمح للمستخدم بمنح نفسه صلاحية المراجعة.
- يمنح مالك نظام الهوية الصلاحيات من جهة موثوقة في Clerk `privateMetadata`:
  - `mateenContentReviewer: true`: مراجعة نسخ النصوص وإدارة المصادر والمساعد.
  - `mateenQualificationReviewer: true`: مراجعة مؤهلات المعلمين ووثائقهم الخاصة.
- ليست الصلاحيتان متلازمتين. لا يُسمح لمراجع المحتوى بتنزيل وثائق المعلم الأصلية دون صلاحية الاعتماد.
- يكفي تسجيل الدخول العادي مع بريد أساسي موثّق وحساب غير محظور أو مقفل والصلاحية الموثوقة المناسبة لعمليات **المراجعة الإدارية**. لا تشترط مَتِين تفعيل MFA أو دليل العامل الثاني للجلسة، حتى إذا كان MFA مفعّلًا للحساب.
- إذا كان البريد غير موثّق، افتح «توثيق البريد الإلكتروني» من بوابة المراجعة، ووثّق البريد الأساسي في ملف الحساب ثم اختر «إنهاء وتحديث الوصول». يُعاد سؤال الخادم بعد تحديث الهوية والجلسة، دون طلب MFA.
- دخول الزائر يعيده بعد تسجيل الدخول إلى مسار مراجعة من قائمة مسارات مسموحة فقط؛ العودة لا تمنح أي صلاحيات.
- يظل MFA اختياريًا في إعدادات أمان الحساب لدى Clerk؛ لم تُغيّر المنصة إعدادات المزود ولا تتجاوز أي خطوة تسجيل دخول يفرضها. حقلا `mfaEnabled` و`secureSession` في عقد حالة الوصول معلومات توافقية وليسا شرطًا للإدارة. لا تُسجل الرموز أو محتويات الوثائق أثناء التشخيص.
- اختبارات الانحدار المحددة: `pnpm --filter @workspace/mateen-platform run test:review-access` و`pnpm --filter @workspace/api-server run test:teacher-review`. تستخدم اختبارات الخادم قاعدة مؤقتة وهوية وتخزينًا معزولين، واختبارات الواجهة بدائل مؤقتة فقط؛ لا تمثل هذه الاختبارات إثباتًا حيًا لصلاحية حساب مراجعة أو لإعداد MFA عند مزود الهوية.
- تقديم المعلم وقراءة وثائقه الخاصة يتطلبان حساب معلم نشطًا وبريدًا موثّقًا، ولا يتطلبان MFA. هذا لا يمنح المعلم صلاحية إدارية أو اعتمادًا تلقائيًا.
- صفحة إعدادات الحساب تستخدم واجهة Clerk للأمان والأجهزة والجلسات. لا تخزن المنصة كلمات المرور أو رموز MFA.

## مراجعة النصوص

- المستورد الأولي هو السجلات الـ42 التي اختارها المستخدم من مرجع تراث، وليس اعتمادًا علميًا أو إذن إعادة استخدام.
- تحتفظ كل نسخة بالنص الحرفي، وبصمة المحتوى، ورقم الصفحة المطبوعة، ورقم صفحة العارض ورابطه، وتعريف الطبعة، وسبب الإنشاء ودليل الحقوق.
- تصحيح النص أو الطبعة أو دليل الحقوق يستلزم نسخة جديدة. لا تُعدّل نسخة معتمدة في مكانها.
- الاعتماد يتطلب مراجعة علمية موثقة للمطابقة واستبعاد الشروح والإضافات التحريرية، ودليل ترخيص أو إذن يسمح بإعادة الاستخدام. لا يستطيع منشئ النسخة إخلاء حقوق نسخته.
- لا يساوي الإتاحة للقراءة الإذن بإعادة الاستخدام. حتى اعتماد نسخة من كل حديث تبقى حالة المتن الإجمالية قيد المراجعة. يظهر وضع كل نسخة للطالب.
- تعتمد ميزات التقييم اللاحقة حصريًا على `getApprovedNawawiRecords()`، مع تثبيت معرف النسخة وبصمتها. هذا التسليم لا يفعّل الاختبارات أو التسميع أو المساعد.

## الوثائق والقرارات

- تُرفع شهادات PDF فقط مباشرة إلى مساحة خاصة في App Storage، بحد 10 ميجابايت للملف و10 ملفات للحساب. الوثائق القديمة المصوّرة لا تحقق شرط شهادة PDF عند إرسال طلب أو اعتماده.
- لا تُتاح الوثيقة حتى التحقق من الحجم والنوع والتوقيع وفحص ClamAV. الفشل أو عدم توفر الفاحص يمنع إتاحتها.
- يحتفظ الخادم بنسخة ثابتة من **البايتات المفحوصة**؛ لا ينسخ كائن الرفع القابل للاستبدال بعد الفحص.
- الفاحص يُنزّل قواعده إلى مجلد تشغيل مؤقت في أول استخدام ويحدثها يوميًا. يجب أن يتوفر `clamscan` و`freshclam` عبر Nix وأن يسمح اتصال الخادم بخدمة تحديث ClamAV. فشل التحديث لا يسمح بتجاوز الفحص.
- يحفظ الإرسال النبذة والتخصصات الظاهرتين في النموذج أولًا، ثم يرسل النسخة الجديدة مع شهادة PDF مفحوصة. تُعرض صفحات PDF محليًا في صفحة المعلم وصفحة `/admin/teachers`، مع التكبير والتنقل بين الصفحات والتنزيل. الإدارة تقبل أو تطلب الاستكمال أو ترفض مع السبب. تُحمى القرارات برقم مراجعة لمنع قبول ملف تغيّر، وتُمنع مراجعة الشخص لطلبه الخاص.
- تغيير النبذة أو التخصصات أو الوثائق يُبطل اعتماد الطلب الحالي؛ تغيير التوفر وحده لا يُبطله. لا ينشر أي مستند أصلي في دليل المشايخ.
- يُسجل إرسال الطلب والقرارات وتغييرات الملف وتنزيل المراجع للوثائق في سجل ملحق فقط. يحمي مشغل قاعدة البيانات سجل المراجعة من UPDATE/DELETE عبر مُشغّل قاعدة بيانات.

## تهيئة البيانات

قاعدة PostgreSQL الحالية باقية، مع جداول إضافية فقط ودون نقل أو حذف بياناتها. يحوي `scripts/post-merge.sh` تثبيت الاعتماديات ومزامنة المخطط وتطبيق حماية سجل المراجعة. لا يعيّن أي دور ولا يعتمد أي مصدر.

قبل الإطلاق العام يجب أن يحدد مالك المنتج سياسة الاحتفاظ بوثائق الطلبات المرفوضة وسجل التدقيق، وإجراءات الحسابات المحذوفة والنسخ الاحتياطية، وتنظيف كائنات الرفع المتروكة. لا تَعِد الواجهة بنسخ احتياطية أو مدد احتفاظ أو حذف قانوني لم يتم إعدادها.
