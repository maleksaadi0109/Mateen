# قياس التنبيهات الصوتية — دون درجات آلية

هذه أداة قياس محلية للحذف والاستبدال فقط؛ لا تختبر النطق أو التشكيل.
لا تكفي موافقة التجربة السابقة، ولا اختيار نموذج، لاعتماد درجات شفهية آلية.
تبقى نتائج الاختبارات الشفهية مبنية على مراجعة بشرية مخولة.

## الحالة وحدود الدليل

قرر صاحب المشروع تأجيل تنفيذ الـbenchmark في 2026-10-03 إلى مرحلة لاحقة.
لا يوقف هذا التأجيل العمل الحالي، ولا يعني تفعيل القياس أو اعتماد درجات
آلية. تبقى أدوات القياس جاهزة للتشغيل لاحقًا ضمن شروط الموافقة والمراجعة.

أضيف مسار قياس جماعي مع فحوص للموافقة والمراجعة وحدود المقطع، لكن لا توجد
عينة موسعة معتمدة لهذا القياس في المستودع. اختبارات الأداة تستخدم بيانات
اصطناعية لا تمثل تسجيلات حقيقية ولا نسب دقة. لا يُعَد إعداد الأداة إتمامًا
للقياس المطلوب؛ لا بد من تنفيذ القياس على تسجيلات مؤهلة وتحليل نتائجه.

يجمع مسؤول القياس تسجيلات جديدة من متحدثين وظروف تسجيل ومقاطع متنوعة
بموافقة صريحة خاصة بهذا الغرض. لا يطلب من صاحب المشروع مجددًا وثائق المصدر
أو تفريغات التسجيلات السابقة، ولا يحوّل التسجيلات السابقة تلقائيًا إلى عينة
قياس. يتولى مراجع سماعي مستقل مخول سماع التسجيل وتحديد الكلام المسموع
وحدود المقطع دون رؤية تفريغ أي نموذج. الانتماء العام إلى دور المعلم لا يكفي.

## الملفات الخاصة والمسؤوليات

- ملف corpus يحدد المعرفات المستعارة والتسجيلات المراد قياسها فقط.
- سجل authorization-ledger مستقل تصدره الجهة المخولة بالمراجعة والموافقة؛
  لا يصدره مقدم التسجيل أو نموذج الذكاء الاصطناعي. تستخدم الأداة السجل
  كشهادة إدارية موثوقة، **ولا تتحقق إلكترونيًا من هوية مصدره**.
  لا يمثل السجل منحًا لصلاحيات التطبيق، ولا يجيز للمشغل تعيين نفسه مراجعًا.
- هذه واجهة تشغيل إدارية محلية، لا ترفع الملفات إلى خدمة خارجية ولا تصدر
  سجل الموافقات من واجهة الطالب. تحفظ ملفات corpus والسجل والنتائج خارج git،
  بصلاحيات خاصة؛ لا تضع فيها أسماء أو بيانات شخصية، بل معرفات مستعارة.
- التسجيلات المستخدمة هنا ملفات محلية داخل `attached_assets` فقط.
  لا تصدر تسجيلات التطبيق/الاختبارات تلقائيًا. إذا كان المصدر اختبارًا،
  يلزم تصريح مستقل وصريح بإعادة استخدام التسجيل المحدد لهذا القياس،
  مع احترام انتهاء صلاحيته وحذفه في المصدر. نسخة محلية متبقية لا تعني
  صلاحية الاستخدام؛ على المسؤول تحديث سجل الحالة من المصدر قبل التشغيل.
- لا تنشر السجل أو التفريغات. تسحب النتائج المشتقة عند سحب الموافقة
  أو انتهاء صلاحية التسجيل، ولا تعيد استخدام تقرير قديم دون فحص الحالة.

## صيغة الإدخال (الإصدار 1)

يمكن البدء بملفي JSON فارغين، لكن ترفض الأداة إجراء قياس على عينة فارغة:

```json
{"schemaVersion": 1, "samples": []}
```

```json
{
  "schemaVersion": 1,
  "purpose": "recitation_alert_benchmark_v1",
  "reviewers": {},
  "samples": {}
}
```

كل عنصر في `corpus.samples` يحتوي على:

| الحقل | المحتوى |
|---|---|
| `id` | معرف التسجيل المستعار والفريد |
| `speakerId` | معرف المتحدث المستعار، ثابت عبر تسجيلاته |
| `conditionId` | حالة التسجيل (مثل هادئ/ضوضاء/جهاز مختلف)، معتمدة في السجل |
| `passageId` | معرف المقطع المختار، معتمد في السجل |
| `origin` | `benchmark` أو `practice` أو `assessment` |
| `audioPath` | مسار التسجيل المحلي |

كل سجل صلاحية عام يحتوي على `status: "active"`، و`issuedAt`، و`expiresAt`
بتوقيت يتضمن المنطقة الزمنية. أي `revokedAt` أو `deletedAt` غير فارغ يرفض
الاستخدام. تستخدم هذه الحقول لسجل التسجيل وسجل الموافقة وسجل تخويل المراجع.

تحت `ledger.reviewers[reviewerId]` تحفظ الجهة المخولة سجل الصلاحية العام
بالإضافة إلى `purpose: "recitation_alert_benchmark_v1"`.

تحت `ledger.samples[id]` تضع الجهة المخولة:

- سجل الصلاحية العام، مع نفس `speakerId` و`conditionId` و`passageId` و`origin`
  و`audioPath` المذكورة في corpus.
- `submittedBy`: معرف مقدم التسجيل المستعار.
- `sha256`: بصمة البايتات نفسها التي تمت الموافقة عليها وسماعها.
- `referenceText`: النص المرجعي الكامل، دون تمريره إلى النموذج.
- `consent`: سجل الصلاحية العام مع `purpose` نفسه و`explicit: true`،
  و`speakerId` و`sha256`. عند المصدر `assessment` يلزم كذلك
  `assessmentReuseExplicit: true`؛ لا يكفي علم الطالب بأن اختباره يسجل.
- `review`: `reviewerId` و`reviewedAt`، و`sha256`،
  و`listenedIndependently: true`، و`asrVisibleDuringReview: false`،
  و`boundariesVerified: true`، و`heardTranscript` لما سمعه المراجع فعلًا،
  و`audioSeconds: [start, end]`، و`referenceWordRange: [start, end]`.
  النطاقات تبدأ من الصفر ونهايتها غير مشمولة. نطاق الكلمات يحسب بعد إزالة
  علامات التشكيل والترقيم والتطويل فقط مع إبقاء الحروف والهمزات.

المراجع مستقل عن المتحدث ومقدم التسجيل، ومخول وقت المراجعة ووقت القياس.
يحدد نفس المقطع المسموع للجميع، ويستبعد المقدمة والعزو؛ لا يصلح الحدود
اعتمادًا على تخمين كلمات ناقصة من خرج النموذج. لا تستبدل المراجعة السماعية
بمجرد تسمية التسجيل «صحيحًا» أو «فيه حذف».

## التشغيل

يجب تثبيت اعتماديات Python المعلنة في `pyproject.toml`، ووجود ffmpeg/ffprobe،
والأوزان المحلية لكلا النموذجين مع manifests تثبت مراجعة النموذج.
لا تنزل أوزانًا أو تسجيلات أثناء القياس.

```sh
.pythonlibs/bin/python scripts/src/compare-local-recitation.py \
  --corpus .cache/recitation-benchmark/corpus.json \
  --authorization-ledger .cache/recitation-benchmark/authorization.json \
  --validate-corpus-only

.pythonlibs/bin/python scripts/src/compare-local-recitation.py \
  --corpus .cache/recitation-benchmark/corpus.json \
  --authorization-ledger .cache/recitation-benchmark/authorization.json
```

`--validate-corpus-only` يثبت أهلية المدخلات فقط، لا يقيس دقة ولا يفعل درجات.
يفحص المسار كاملًا قبل تحميل الأوزان؛ يعيد فحص الحالة والبصمة لكل تسجيل قبل
كل مزود وبعد التعرف وقبل حفظ التقرير. تغير المراجعة أثناء التشغيل يمنع خلط
مرجعين مختلفين. تنشر النتائج محليًا في `.cache/recitation-experiments`
بصلاحية مجلد `0700` وملف `0600`.

مسار `--audio --consent-confirmed` القديم باقٍ للتشخيص المأذون سابقًا فقط،
ويخرج `benchmarkEligible: false`. لا تُضم نتائجه إلى القياس الجماعي.

## تفسير القياس

- تطابق التنبيه يتطلب **نفس نوع الخطأ ونفس نطاق الكلمات المرجعية** كما يظهر
  في محاذاة التفريغ السماعي. وجود كلمة في التسجيل وحده لا يكفي.
- يعرض لكل نموذج ومراجعته: أحداث الحذف والاستبدال المرجعية، المكتشفة،
  الفائتة، والتنبيهات غير المطابقة. الخطأ في الموضع أو النوع يحسب حدثًا
  فائتًا وتنبيهًا خاطئًا، لا اكتشافًا صحيحًا.
- يعرض precision/recall للأحداث بمقامات واضحة؛ عند انعدام المقام تكون القيمة
  `null`، لا صفرًا ولا «دقة 100%». ليس هذا معدل دقة عام للطالب أو للنموذج.
- يعرض عدد المقاطع الصحيحة سماعيًا التي تلقت تنبيهًا خاطئًا ونسبتها. اختلاف
  ASR عن الكلام المسموع يبقى تشخيصًا للنموذج، وليس خطأ مثبتًا على الطالب.
- حذف الكلمات عند طرف غير مرصود، والكلمات الإضافية، تظهر في مقاييس
  `unscored*Spans` ولا تدخل أحداث الحذف والاستبدال. لذلك لا يغطي هذا القياس
  جميع الأخطاء المحتملة. البداية/النهاية غير الموثقتين في مسار التدريب
  تظلان غير مؤكدتين، حتى لو كان الاختلاف استبدالًا.
- الزمن يشمل لكل تشغيل تحميل النموذج ووقت التعرف والوقت الدافئ ونسبة
  زمن التعرف إلى طول المقطع، مع median وp95 بطريقة nearest-rank. وقت التحميل
  البارد منفصل، ولا يمثل أداء الإنتاج.
- يعرض التغطية والتقسيم حسب المتحدث والحالة والمقطع. ترفض التسجيلات المكررة
  بالبايتات كي لا تضخم التغطية. قلة التنوع أو العينات لا تختفي خلف المتوسط.
- يسجل التشغيل غير القابل للاستخدام/المبتور ضمن `failures`؛ لا يحسبه خطأ
  طالب ولا إدخالًا صحيحًا. `allRequestedRunsMeasured` يوضح نقص التشغيل.
- المحاذاة حتمية وليست حكمًا علميًا؛ التكرار والدمج واختلاف تقسيم الكلمات
  قد يغيران نطاق الحدث. ينبغي للمراجع فحص الخلافات قبل أي استنتاج أوسع.

## قبل التفكير في الدرجات الآلية

لا تقبل الأداة سياسة درجات ولا تتغير `approvedForAssessment: false` مهما
تحسنت النتائج. يراجع أصحاب الاختصاص النتائج الفعلية والتنوع والمقامات
والإنذارات الخاطئة والفشل والمقاطع المستبعدة، ويحددون سياسة قبول مستقلة
وتقييمًا على عينة أخرى قبل أي تغيير في التصحيح. لا تضع نسبة نجاح تخمينية
ولا عتبة قبول بمجرد اختيار مزود.
