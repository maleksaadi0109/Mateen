# نموذج الصوت المحلي للتجربة

## الاختيار

- النموذج: **Qwen/Qwen3-ASR-0.6B-hf**، من مستودع Qwen الرسمي.
- المصدر: https://huggingface.co/Qwen/Qwen3-ASR-0.6B-hf
- الترخيص المعلن في بطاقة النموذج: **Apache 2.0**.
- الإصدار المثبت: `7f1569a48a89f3e3f4dc3a5c9d28bddd903bc76c`.
- الحجم الإجمالي للملفات المختارة: **1,576,379,761 بايت** (نحو 1.58 GB).
- يدعم العربية وفق توثيق المشروع: https://github.com/QwenLM/Qwen3-ASR

اختير الحجم الأصغر لتجربة أولية، وليس بسبب دقة مثبتة في تسميع الأربعين النووية.

## التنزيل والتحقق

من جذر مساحة المشروع:

```sh
python scripts/src/download-local-recitation-model.py
```

مكان الملفات: `.cache/recitation-models/qwen3-asr-0.6b-hf/`.
هذا المجلد مستبعد من Git؛ الأوزان ليست جزءًا من مصدر التطبيق.
يسجّل `download-manifest.json` المصدر والإصدار وأحجام الملفات والبصمات.

لإعادة فحص الملفات دون تنزيل:

```sh
python scripts/src/download-local-recitation-model.py --verify-only
```

يتحقق التنزيل من الحجم والبصمة قبل اعتماد كل ملف، ويستخدم ملفات مؤقتة ثم
يستبدلها بعد اكتمال التحقق. أسماء الملفات والمصدر والإصدار ثابتة، ولا يقبل
البرنامج روابط أو مسارات من المستخدم. لا يرفع صوتًا ولا ينفذ شيفرة من مستودع
النموذج. الأوزان بصيغة Safetensors.

## التشغيل المحلي — تجربة منفذة بتاريخ 2026-10-02

ثُبتت مكتبات التشغيل في بيئة Python المدارة الموجودة، دون إنشاء بيئة أخرى.
التجربة تستخدم PyTorch CPU وTransformers الأصلي، ولا تنفذ شيفرة بعيدة من
مستودع النموذج. أُوقفت اتصالات الشبكة في عملية الاستدلال، واستخدمت الأوزان
المحلية فقط دون تلميحات تتضمن الإجابة المرجعية.

الأمر من جذر مساحة المشروع، بعد موافقة صاحب التسجيل على التجربة:

```sh
python scripts/src/transcribe-local-recitation.py \
  --audio attached_assets/sample.mp3 --consent-confirmed
```

الحدود: MP3 داخل `attached_assets` فقط، بحد 10 MiB وثلاث دقائق. يستخدم فك
الصوت قائمة معاملات دون صدفة أوامر، ويسمح ببروتوكولي الملفات والأنابيب فقط.
لا تُحفظ نسخة صوت مفكوكة؛ تمر العينات في الذاكرة.

نتيجة العينة الحقيقية المأذون بها:

| القياس | النتيجة الفعلية |
| --- | --- |
| مدة المصدر | 20.04 ثانية |
| تحميل النموذج | 24.830 ثانية |
| تجهيز الصوت | 0.415 ثانية |
| الاستدلال | 5.084 ثوانٍ |
| من بدء التحميل حتى النتيجة، دون استيراد المكتبات | 30.330 ثانية |
| ذروة ذاكرة العملية | 5025.3 MiB |
| المعالج | CPU، أربع خيوط، float32 |
| بلوغ نهاية التوليد | نعم؛ لا علامة اقتطاع بحد الرموز |
| رفع الصوت | لا |
| درجة الطالب أو دقة معتمدة | لا |

التفريغ الخام ونسخة النموذج والإعدادات والبصمة محفوظة في
`.cache/recitation-experiments/`، المستبعد من Git. المجلد خاص بصلاحية `0700`
والنتائج بصلاحية `0600`. يمكن حذف ملف النتيجة محليًا؛ البرنامج لا يعيد رفعه
أو إنشاءه إلا عند تشغيل تجربة جديدة. هذه ليست بعد سياسة احتفاظ صوت الطلاب
على خادم إنتاج.

جرت فحوص حدود الملفات والمسارات والمدة ومنع الشبكة، وفحص تجهيز الصوت بعد
تعديل تمرير معدل العينات بما يلائم واجهة المعالج. لم يُكرر الاستدلال لمجرد
هذا التعديل؛ النتيجة الأصلية كانت تستخدم معدل 16 kHz نفسه.

## الحدود المتبقية

شُغّل النموذج وأنتج تفريغًا حقيقيًا، لكنه لم يُربط بتسميع الطلاب أو الدرجات.
لا يوجد تفريغ بشري مستقل لهذه العينة، ولذلك لا توجد نسبة دقة أو أخطاء
محسوبة. بعض الكلمات الناتجة تحتاج مراجعة، ولا يجوز نسبتها تلقائيًا إلى
خطأ القارئ أو استبدالها بالنص المتوقع.

يجب مقارنة النتائج بتفريغ بشري وعينات حذف واستبدال قبل اعتماد أي درجات.
نسخة ForcedAligner المنشورة لا تدرج العربية ضمن لغاتها المدعومة؛ لا تُفترض
صلاحيتها لمحاذاة التسميع العربي.

لا يتغير شرط مراجعة النص المنقول وحقوق استخدامه، ولا تُفعّل الاختبارات أو
الترقية أو المراجعات المجدولة بمجرد وجود النموذج.
