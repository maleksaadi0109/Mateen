# مَتِين — عرض الفكرة للتسجيل

## الملفات والتشغيل

- `generate_mateen.py`: كود كامل مستقل يولّد عشر شرائح قابلة للتحرير بنسبة 16:9.
- `mateen-registration.pptx`: العرض الناتج، ويتضمن ملاحظات متحدث للمصادر والمنهجية والحدود.
- `mateen-registration.pdf`: نسخة للقراءة تحافظ على المظهر دون الحاجة إلى الخطوط.

```bash
python -m pip install "python-pptx>=1.0.2,<2"
python generate_mateen.py --output mateen-registration.pptx
```

يلزم تثبيت Kufam وCairo وNoto Naskh Arabic على جهاز تحرير العرض؛ الخطوط ليست مضمنة في PPTX. لا يحتاج الكود إلى الاتصال بالإنترنت أو ملفات التطبيق أو بيانات المشاركين. البطاقات أشكال PowerPoint قابلة للتحرير وليست عناصر ويب تفاعلية. يُحافظ على النص العربي بترتيبه المنطقي مع اتجاه RTL وخط النص المركب؛ لا يُعكس النص يدوياً.

### حدود مهمة

- 47 مشاركاً يدرسون متوناً أو منظومات أو كليهما، و13 لا يدرسون أياً منهما حالياً؛ لذلك استُخدمت «60 استجابة» بدلاً من «60 طالباً متخصصاً».
- السؤال الثاني طلب أهم عائقين، لكن خمس استجابات تضمنت ثلاثة عوائق؛ احتُفظ بها دون تغيير أو حذف صامت.
- السؤال الرابع سأل عن تصحيح النطق والتشكيل، وهو أوسع من النطاق الأول المعتمد. لم يُستخدم لإثبات الطلب على تقييم الكلمات وحده.
- لا يُستنتج من هذا الاستبيان تحسّن تعليمي أو حجم سوق أو استعداد للدفع أو دقة تقنية.

## بيانات لا يجوز اختلاقها قبل التقديم

الأسماء والخبرات الفعلية للفريق وأدلته، المرجع العلمي والطبعة وترخيصها، وتوافر المختصين. لم تُختلق هذه المعلومات في العرض؛ الأدوار وتغطيتها مقترحة. يجب استكمال بيانات القدرة الفعلية في استمارة التسجيل.

## حدود العرض

هذا عرض لفكرة وخطة؛ لا صور للتطبيق أو روابط تطوير أو إشارة إلى تنفيذ سابق، ولا ادعاء بعدم وجود عمل سابق. لا «جاهز للتشغيل»، ولا تصحيح نطق أو تشكيل في النطاق الأول، ولا ضمان صفر هلوسة أو دقة 95% أو زمن 300ms. الأهداف والاختبارات المستقبلية ليست نتائج محققة.
